# Голицынский керамический завод — premium landing

Одностраничный премиальный лендинг для ОАО «Голицынский керамический завод», собранный на React, Tailwind CSS, Framer Motion и lucide-react.

## Стек

- React + Vite
- Tailwind CSS
- Framer Motion
- lucide-react

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
